workflow.steps의 minTier/risk/kind는 라우터가 보는 정보, tasks[].steps의 needs(이 티어 미만이면 도구 인자 누락)·refuseBelow(이 티어 미만이면 거절)는 목업 모델의 숨은 정답이에요.

      
      

    

  


  

    동작 규칙
    
    
      
  • 작업 시작 때 한 번 티어·effort를 정하고 작업 동안 고정해요. 워크플로 하한(minTier, 계획·고위험 단계는 effort ≥ medium) 아래로는 내려가지 않아요.
    • 
      
  • 캐시가 살아 있으면(Claude 5분, GPT 30분) 다음 작업에서도 하위 티어로 내리지 않아요. 프롬프트 캐시는 모델별이라 바꾸면 다시 써야 해요.
    • 
      
  • 도구 오류 2회 연속 또는 거절(content_filtered / refusal)이면 effort는 그대로 두고 한 단계 위 티어로 올려요. 이미 최상위면 effort를 high로 올려요.
    • 
      
  • Claude 5.5 가격은 Bedrock 모델 카드에 없어 가정값($1/$3/$5 입력, $5/$15/$25 출력)이에요. 캐시 규칙·토큰 수(글자/3)도 단순화한 시뮬레이션이에요.
